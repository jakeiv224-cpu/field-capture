    How this works, and what it does not do

    The place comes from this phone's location at the moment you take the photo, and the time from this phone's clock. Both are written into the photo and into the list that travels with it, with how accurate the location fix was.

    A photo picked from your library never gets today's location: it keeps whatever place it already carries, or none.

    If a photo already carries a place from the camera, the file is kept byte for byte. Otherwise the place is added to the photo's details; the picture itself is not re-compressed. The list records which happened, with a fingerprint of the file before and after.

    Photos stay in this browser on this phone. Clearing the browser's site data removes them, so send often.
